# Media

Photos, videos, screenshots and the poster. You will need far more of them for the final report and presentation than you expect. **Capture every stage**: parts laid out, half-assembled, wiring before closing up, first power-on, first working demo, failures. Software and ML projects: screenshots of the interface, dashboards and training curves, and screen recordings of demos.

## Layout

```
media/
├── photos/     YYYY-MM-DD-short-description.jpg (photos and screenshots)
├── videos/     only short clips (< 20 MB); link longer ones below
└── poster/     poster source and PDF export
```

Resize photos before committing (about 1600 px on the long edge is plenty). Larger files follow the team's [large-file policy](../CONTRIBUTING.md#large-files).
