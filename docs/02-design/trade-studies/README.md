# Trade Studies

A trade study compares options for one design question against weighted criteria, so the choice is justified rather than guessed. Do one for every major choice, e.g. platform, main sensor, microcontroller or computer, connectivity, cloud or server stack, key algorithm, model architecture, or where the model runs.

Create one with:

```bash
python tools/new.py trade-study "Which microcontroller?"
```

The script adds a row to the index below. Fill in the remaining cells once the study is done. See the [worked example](../../../templates/examples/TS-001-example.md).
