# Phase Reviews

One phase review is written by the whole team (or by you, if solo) at the end of each phase, before the gate meeting. It shows the mentor what was achieved, the evidence, how the project stands against the plan, and what happens next. The mentor records the gate outcome at the bottom.

Create one with:

```bash
python tools/new.py review 1    # 1 = Define, 2 = Design, 3 = Build & Integrate, 4 = Test & Validate, 5 = Deliver
```

Gate checklists are in [phases.md](../../05-management/phases.md). Gate presentation slides (exported to PDF) go in `assets/` in this folder and are linked from the review. See the [worked example](../../../templates/examples/phase-2-review-example.md).
