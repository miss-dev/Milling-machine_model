## Repository layout

```
docs/        All writing: project, requirements, design, testing, management, reports, meetings
src/         All code (layout depends on your stack, see src/README.md)
hardware/    CAD, electrical schematics, datasheets, bill of materials (delete if software-only)
data/        Experiment data, logs and dataset cards
media/       Photos, videos, poster
templates/   Blank templates and worked examples for repeatable documents
tools/       Helper scripts: create documents from templates, check the docs
```

The full documentation map is in [docs/README.md](docs/README.md).
